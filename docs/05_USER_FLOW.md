# UrbanFlow - User Flow
## Researcher
Login -> Experiments -> Scenario -> Controller -> Configuration -> Run -> Results -> Comparison.

## Operator
Login -> Dashboard -> Intersection -> Live View -> Traffic/Signal/Agent monitoring -> Alerts.

## Administrator
Login -> Intersections/Configuration -> Edit -> Validate -> Save -> Audit.

## System
Input -> Perception -> State -> Agents -> Coordination -> Policy -> Safety -> Signal -> New state.
