# UrbanFlow UI Error States

## Categories
- Network unavailable
- Authentication failure
- Authorization denied
- Intersection unavailable
- Sensor data unavailable
- AI service unavailable
- Simulation failed
- Invalid configuration

## Error UI
Each error should state:
1. what failed;
2. whether data is stale;
3. what the user can safely do next.

Never display an AI failure as a successful signal-control action.
