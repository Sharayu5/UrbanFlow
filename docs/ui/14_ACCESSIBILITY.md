# UrbanFlow Accessibility

## Requirements
- Keyboard navigable controls.
- Visible focus state.
- Semantic headings.
- Accessible labels for charts and controls.
- Sufficient text/background contrast.
- Do not rely only on color for traffic status.
- Provide textual alternatives for signal and lane states.
- Respect reduced-motion preferences.

## Data visualization
Charts should provide accessible summaries or tabular alternatives.
