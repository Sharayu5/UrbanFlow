# UrbanFlow User Journeys

## Journey 1: Monitor Live Traffic
Login -> Dashboard -> Select Intersection -> Live View -> Inspect lanes -> Inspect signal phase -> Review alerts.

## Journey 2: Run Research Experiment
Login -> Experiments -> New Experiment -> Choose scenario -> Choose controller -> Configure -> Run -> Monitor -> Results -> Compare.

## Journey 3: Analyze AI Decision
Dashboard -> AI Agents -> Select Lane Agent -> Inspect local state -> Open Project Manager -> Inspect selected action -> Review signal validation.

## Journey 4: Configure Intersection
Administrator -> Configuration -> Select intersection -> Edit geometry/phases/safety limits -> Validate -> Save -> Audit log.

## Journey 5: Investigate Failure
Alert -> Error details -> Last valid state -> Controller status -> Fallback status -> Logs -> Resolution.

## Principle
Every journey should clearly distinguish observation, configuration and actual control authorization.
