# UrbanFlow UI Design System

## Visual language
The interface should feel technical, calm and operational.

## Components
- App shell
- Sidebar/navigation
- Intersection card
- Lane status card
- Signal phase indicator
- Agent status panel
- Metric card
- Traffic chart
- Experiment table
- Alert banner
- Configuration form
- Confirmation dialog

## Status vocabulary
Use clear states such as:
- LIVE
- DELAYED
- STALE
- ACTIVE
- COMPLETED
- FAILED
- SAFE FALLBACK

Avoid relying on color alone to communicate status.
