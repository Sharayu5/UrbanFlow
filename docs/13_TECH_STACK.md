# UrbanFlow - Technology Stack
Backend: Python, FastAPI, Pydantic, Uvicorn.
Vision: OpenCV, YOLO-compatible detector, object tracking.
AI: NumPy, Pandas, PyTorch-based tooling where required.
Simulation: SUMO and TraCI.
Database: Firestore for operational/configuration data plus suitable telemetry storage.
Frontend: Web dashboard.
Development: Git, tests, environment-based configuration.
