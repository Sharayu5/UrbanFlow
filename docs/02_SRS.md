# UrbanFlow - Software Requirements Specification
## Functional requirements
1. Accept simulation, recorded video and supported live traffic inputs.
2. Detect and track vehicles.
3. Map vehicles to lanes/approaches.
4. Estimate count, queue, speed, arrival rate, waiting time and occupancy.
5. Smooth noisy observations.
6. Run independent Lane Agents.
7. Coordinate agents through a Project Manager Agent.
8. Select valid signal actions.
9. Enforce safety constraints.
10. Log decisions and metrics.
11. Run repeatable experiments.
12. Compare UrbanFlow with baseline controllers.

## Non-functional requirements
Real-time/near-real-time operation, modularity, reliability, security, reproducibility, scalability and auditability.
